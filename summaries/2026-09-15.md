## [tech] Tailwind CSS v4にしたらShadow DOMの中で一部のスタイルが効かなくなったので調べてみた | iimon TECH BLOG
- **Date:** 2026/09/15 15:16:05
- **Link:** https://tech.iimon.co.jp/entry/2026/09/15/201802

### 要約
Tailwind CSS v4へ更新後、Shadow DOM内で一部スタイルが効かなくなる問題について解説。
原因はv4のアーキテクチャ変更にあり、`@property`がshadow root内で登録されず、CSSカスタムプロパティを用いたスタイル定義が無効化されてしまうためです。
この仕様変更により、特に`box-shadow`などが影響を受け、v4とShadow DOMを併用する際には注意が必要です。
